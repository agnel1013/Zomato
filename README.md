# Zomato Data Visualization & Insights
Interactive Zomato analytics dashboard built with Microsoft Power BI, featuring executive overview, customer analytics, restaurant performance, delivery operations, and detailed insights.
## Dashboard Overview

The Zomato Power BI dashboard consists of six interactive report pages:

### 1. Executive Overview

Provides a high-level summary of key business metrics and an overview of Zomato-related data.

### 2. Customer Analytics

Focuses on customer-related data to help explore customer patterns and behavior.

### 3. Restaurant Performance

Presents restaurant-related information to support performance comparisons and analysis.

### 4. Delivery and Operations

Focuses on delivery and operational data to explore service-related patterns and performance.

### 5. Advanced Insights

Provides a deeper view of the data to explore trends, comparisons, and potential business insights.

### 6. Restaurant Details

Displays detailed restaurant-level information for more specific analysis and exploration.
